# Novo Nordisk - Strategy Review

Novo Nordisk’s selloff masks strong fundamentals: elite margins, integrated manufacturing, and a foundation-backed governance advantage. 
My review shows how to turn these into growth: diversify beyond semaglutide (RNAi, amylin), scale next-gen biologics, and deploy 
the capital structure (targeted leverage) to fund capacity/M&A—while using outcomes data and bundled cardiometabolic contracts to defend access and leadership.
